# Refonte issue de l'audit des écrans

1. Capturer les parcours concurrents et l'arrivée actuelle de Travaux ; relever positions du document, modes de lecture, détail et preuves.
2. Remplacer la structure de dossier : rail de chantiers, contenu central, vues explicites, métadonnées compactes, blocs trouvables.
3. Relier les annonces d'action confirmées aux mêmes lignes natives par une correspondance persistante ; les réouvertures conservent les changements humains.
4. Conserver les octets originaux des nouveaux imports et donner une vue Documents avec ouverture de l'extrait et téléchargement de l'original disponible.
5. Tester les vraies vues AFFiNE, la persistance, les conflits, les liens mail/document et le mobile. Comparer avant/après et auditer les échecs.
6. Construire, publier sur le staging protégé existant et vérifier le résultat public. Ne pas annoncer de connexion institutionnelle ou de conformité acquise.
