# Audit avant correction — 14 novembre 2026

Périmètre : complément web local sur `http://127.0.0.1:8765`, données entièrement fictives, parcours du responsable travaux : retrouver un chantier, lire son évolution, comparer la preuve, noter un constat, relire un récapitulatif. Stack : JavaScript natif, templates HTML, CSS à tokens sémantiques, sans bibliothèque de composants. Convention trouvée : `docs/design.md`. Audit en lecture seule ; les requêtes de mutation ont été bloquées dans Playwright. La vue native AppFlowy n'était pas raccordée : aucune conclusion sur son UX, ni sur celle du moteur AFFiNE retenu ensuite.

Application réelle de `better-interface` et de ses six compétences propriétaires : références clavier/focus, formulaires, noms accessibles, cibles, mouvement/zoom, adaptativité, contraste, tailles typographiques, rédaction et animations lues avant inspection. Les captures sont celles de l'état observé **avant** correction ; le rapport après correction sera séparé.

## Vérifications et limites

- Scripts exécutés avant correction : `work/audit_interface.py`, `work/audit_interface_extra.py`, `work/audit_interface_flows.py`, via `.venv/Scripts/python.exe`, Playwright/Chrome réel. Les JSON et PNG sont dans [evidence-avant](evidence-avant/).
- 28 vues rendues à1440/720/390/320px, zéro erreur JavaScript observée et zéro mutation envoyée. Aucun débordement horizontal global. Les fiches chantier, sources, imports et récapitulatifs s'empilent réellement ; le menu bas reste accessible.
- Référence exacte `TRV-2026-014` : bon chantier retrouvé quand le filtre d'état est remis à « Tous ». Le premier relevé `search_reference` dans `mesures.json` avait conservé le filtre Clôturés ; le contrôle isolé corrigé est `exact_search` dans `mesures-extra.json`.
- Dialog source : nom « Document source », fermeture Échap, retour sur « Ouvrir le mail source ». Contrôles majeurs mobiles ≥44px de haut. Les liens textuels plus petits ne sont pas classés automatiquement non conformes : exceptions de cibles et espacement pris en compte.
- Chargement : `role=status`, skeletons sans animation avec reduced-motion. Vide : action d'import.503 : message et bouton Réessayer. Les captures définitives d'erreur/vide sont celles préfixées390 ; les premières captures1440 ont saisi l'amorçage et ne constituent pas une preuve de l'état final.
-720 CSS px constitue le test de reflow équivalent à une fenêtre1440px au zoom200 %. Test distinct de redimensionnement du texte : tailles calculées doublées à1440px. **Le raccourci de zoom du navigateur et une restitution audio NVDA/VoiceOver n'ont pas été vérifiés.** L'AX et le clavier ont été inspectés ; ceci n'est pas un audit RGAA complet.

**Verdict initial : Block.** Les défauts HIGH ci-dessus doivent être corrigés avant de présenter cette interface comme prête pour un pilote métier. Cette conclusion porte sur l'interface complémentaire observée, pas sur la conformité RGPD ni sur un moteur natif non connecté.
