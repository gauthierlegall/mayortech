# Provenance des ressources

`login/resources/css/mayortech.css` et `login/resources/img/mayortech-mark.svg` sont des ressources originales rédigées pour MayorTech. Le signe de bâtiment est illustratif ; il ne reproduit pas le blason ou l’identité officielle de Plougastel-Daoulas.

Les formulaires, traductions natives, actions, champs de mot de passe, TOTP, passkeys et scripts restent ceux du parent officiel `keycloak.v2` de Keycloak26.8.2. Aucun fichier FTL, JavaScript ou classe Java de ce parent n’est copié dans le thème.

Les seules ressources tierces incluses sont les deux polices DM Sans avec leur licence OFL ; voir `FONT_LICENSE.md`. Les propriétés et le CSS ajoutent une présentation, sans remplacer une règle d’authentification.
