# Règle Permanente : Visual QA & Conformité Design System Light Mode

Après toute modification UI/React/CSS (y compris sur les Pôles 1 à 5), exécute obligatoirement le skill `visual-qa` et applique le Design System Light Mode natif de MayorTech (style Linear / Stripe / n8n). 

Interdiction absolue d'introduire des blocs sombres `#070B14` ou des badges marketing/debug (`60 FPS`, `DYNAMIQUE`, `Licence 0 €`, etc.).

Tout rendu de canvas doit reposer sur un fond lumineux (`bg-slate-50 border border-slate-200 rounded-2xl`) avec grille discrète et cartes blanches compactes.
